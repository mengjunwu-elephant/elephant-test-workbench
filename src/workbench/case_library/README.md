# 本项目用例资产

此目录随本项目源码 Git 提交，应用运行时仅访问本项目文件，不依赖旧工程存在。

- `cases/<机型>/*.json`：用例定义、原始参数组、来源行号、转换状态与前置/验证/恢复步骤。
- `sources/**/*.txt`：经授权从 elephant-pytest 一次性迁入的测试、fixture 和公共方法逻辑依据，仅查看，绝不导入或执行。设备初始化、连接地址和环境密钥配置不作为运行依赖迁移。
- `migration-manifest.json`：来源哈希、空表、文件覆盖范围及转换限制。

2026-11-13 核对：9 个工作簿、457 张工作表、3,232 组参数；456 份非空用例，14 份只读场景已转为读取/断言步骤，442 份复杂场景待完善且禁用；1 张空表记录在清单。源测试文件 514 个、测试函数 835 个；这些数量的含义不同，不当作可执行用例数量。

原 Excel 字符串保持原样，不执行 eval。包含防碰撞条件、运动、人工输入、双臂、特殊异常或 fixture 恢复依赖的场景，不得删掉关键逻辑后冒充迁移完成。编排页需用实际步骤替换 review 条目并启用；后端同时阻断未启用/待完善用例。

使用流程：保存草稿 → 写回文件 → 审查差异 → Git 提交 → 推送。另一工作区拉取后载入文件。设备连接、SDK、数据库、日志、结果不写入此目录。冲突需要人工处理，不自动覆盖；源码拉取接受整个工作区干净的快进更新。

迁移脚本位于项目 scripts/，只接受明确指定的来源，并拒绝覆盖已有资产。简单只读转换脚本仅做 AST 解析，不能证明 SDK/固件或实机兼容性。
